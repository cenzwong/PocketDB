# Browser protocol package

`@pocketdb/protocol` implements the version 1 browser JSON envelope, engine-aware request metadata, correlated replies, structured errors, tagged binary and SQL payload values, and bounded encoding/decoding. It also creates and parses versioned capability invitations for `pocketdb://` URIs and browser fragment links.

Invitation capabilities are cryptographically random 256-bit values. Invitation payloads live in the URL fragment; query strings are rejected and the log helper removes query and fragment data. The parser checks format, expiry and an optional expected target, but invitation parsing alone does not authenticate a peer or enforce authorization. `PeerSessionAuthority` implements a Web Crypto P-256 challenge/proof exchange: the host key is pinned by the invitation, both DTLS fingerprints and the invitation's room/instance/engine/access/expiry are signed, the client proves key possession, and the capability is verified with HMAC. `readPeerBinding` reads connected local and remote certificate fingerprints from WebRTC stats. The authority bounds pending challenges and active sessions, issues connection-bound sessions, gates handlers through `runAuthorized`, and revokes all sessions on `revoke()`; callers should close the returned engine sessions. Rejection callbacks receive only a stable code and event name, never invitation or proof contents. Write-enabled browser links include a warning for the caller to show before copying.

The WebRTC browser integration passed in Chrome Canary 160.0.8181.0 and Edge 116.0.1938.62. It proves the handshake with local peers and the fingerprints reported by those browser transports; Edge 116 is legacy feasibility evidence, not a current support claim. Revocation blocks later handler dispatch but does not cancel a handler that already began executing.

See the [protocol specification](../../docs/specs/protocol-v1.md), [remote-access and invitation specification](../../docs/specs/remote-access.md) and [executable protocol fixtures](fixtures/v1-messages.json). Run `pnpm --filter @pocketdb/protocol typecheck`, `pnpm --filter @pocketdb/protocol test` and `pnpm --filter @pocketdb/protocol test:browser` from the repository root.
